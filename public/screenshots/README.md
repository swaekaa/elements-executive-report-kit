# Screenshot Placeholders

Replace these files with actual screenshots after running the project locally.

## Files to create:

- `executive-report.png` — Full executive report template screenshot
- `research-report.png` — Full research report template screenshot
- `security-audit.png` — Full security audit report template screenshot
- `preview-app.png` — Preview application with toolbar and template tabs

## How to capture:

1. Run `npm run dev`
2. Open `http://localhost:5173` in your browser
3. Switch to each template using the tabs
4. Use your browser's screenshot tool or a tool like [Greenshot](https://getgreenshot.org/)
5. Save screenshots to this directory
